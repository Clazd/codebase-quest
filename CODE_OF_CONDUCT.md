# Code of Conduct

Codebase Quest adopts the **[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)**
as its code of conduct. It applies to everyone in every project space: issues,
pull requests, discussions, chat, and events where you represent the project.

In short: be welcoming, kind and patient; assume good intent; give and accept
constructive feedback gracefully; and never harass, demean or exclude anyone.
The full text linked above is what counts.

## Enforcement

Maintainers follow the enforcement guidelines in the Contributor Covenant 3.0:
from a private warning for a first, minor issue up to a permanent ban for
sustained or severe harm.
